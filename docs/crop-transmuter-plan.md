# 作物嬗变仪

一个新的工作方块，用于解决原先作物果实只能产生一种材料物品的问题。

## 行为

像普通的工作方块一样，右键打开菜单。

- 左侧是一个物品输入槽位，接受 Crop、Melon 等作物果实
- 中间为物品选择，显示所有可用的材料输出，默认选中第一个
- 右侧为一个物品输出槽位，用于暂存材料输出
- 红石信号控制启停，默认为正逻辑（有红石信号则启动嬗变）
- 菜单右上方添加一个按钮，用于切换红石正/反逻辑

### 细则

#### 持久化

- 输入输出槽位物品
- 当前选择的索引（用一个short或者byte即可，注意输入物品的更换不应该导致索引存储的改变；若索引超出材料物品列表，使用
  `min(material_len, selection)`）

#### 存储交互

- 模组自身的 Repo API 实现模组存储交互
- 需要能够与漏斗/漏斗矿车交互
